# Markdown Guides and Test Files

Each document comes in two flavors:

- **MD source** – the original file, meant to be viewed in **Markdown Preview
  Enhanced** (MPE) with this theme. Diagrams and custom classes don't render on
  GitHub.
- **GFM export** – a GitHub Flavored Markdown export (`.gfm.md`) with diagrams
  rendered to images, readable directly on GitHub.
